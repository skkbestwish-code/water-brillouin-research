## 2. 优先处理的问题

以下行号对应 `原包解压/常压水_瑞利布里渊_FP模拟_2026-10-01` 中的未修改源码。P1为影响项目验收或证据可信性的优先项；P2为必须在正式复用前补齐的功能、适用范围或表述问题。

### F01 / P1：将历史假设写成“已确认条件”，且输出元数据写死

**证据：** `README.md:23`（另一份 README 同样如此）；`run_water_simulation.py:84—85`。输出 `confirmed` 固定写 He–Ne、FSR=15 GHz、精细度30及FP外部空气，不读取配置中的实际值，更没有相应确认文件。当前项目提示词明确要求这些历史条件重新核查。

**影响：** 不仅默认报告可能误导实验选型，修改配置后仍可能出现配置表与“已确认参数”矛盾，损害图表溯源。

**改进：** 将这些值改为“历史参考假设”；由实际配置生成运行元数据，另设来源、状态、适用范围和确认记录字段。确认状态只能由真实证据更新。不能只改 README 而保留写死的 `confirmed`。

### F02 / P1：优化器成功与科学结果合格没有独立判据

**证据：** `water_simulation/inverse.py:48` 返回优化器的 `success`，另记 `at_bound`；`run_water_simulation.py:247—248` 的 `all_success` 仅汇总前者。方法说明已正确警告两者不同，但程序尚未把警告变成验收逻辑。默认重跑低计数12次中有1次参数触边，`all_success` 仍为真；腔介质错误的失配算例返回 `success=True`、`at_bound=True`，平均标准化残差平方约36003。

**影响：** 下游若直接按成功标志计入有效样本或统计失败率，会漏掉不可接受的拟合。触边本身不必一律剔除，但必须按预先定义的目标参数与质量规则标记，不能默认等同于有效结果。

**改进：** 分开输出 `optimizer_success`、`quality_pass` 和原因列表；先约定非有限值、未收敛、关键参数触边、严重残差、不可辨识或不确定度异常如何处理。保存优化器停止信息、所有失败样本和总尝试次数。模拟真值误差单独评价，不将实验无法知道的真值用于实验质控。

### F03 / P1：噪声验证只有两档各12次，不满足三档各50次

**证据：** `run_water_simulation.py:41,240—248`；重跑结果共24条拟合摘要。两档用每像素相对信号尺度2000和25电子，背景20电子、读出噪声标准差3电子。不是三档 SNR，也不是相机电子/ADU增益。种子规则为 `seed+1000+j`，同一档内不同，跨档复用同一序列。

**影响：** 不能签署M04—M06完成；缺少预先锁定的第三档、合格/失败定义和失败率。已有独立噪声实现可以保留，但不能把重复数扩大解释为已完成150次。

**改进：** 先冻结同一真值、三档噪声定义、独立种子分配、约束及失败规则，再逐次运行并保存种子、输入/观测关联、结果、质控状态和原因。统计偏差、标准差、RMSE及失败率；失败样本保留在总尝试数分母。若有意采用跨档配对随机数，应单独说明，不能同时声称全部实现相互独立。

### F04 / P2：输入允许范围比拟合器适用范围宽

**证据：** `water_simulation/physics.py` 的 `Water.__post_init__` 接受所有0—180°内部角（不含0）；`water_simulation/inverse.py:39—40` 将频移范围固定为1—8 GHz，HWHM固定为0.015—1 GHz，初值固定4.2 GHz。本轮10°无噪声数据真值为0.543936550 GHz，返回1.000000000 GHz、触边且 `success=True`，平均标准化残差平方约108674。

**影响：** 用户按 README 修改合法参数时，可能获得形式上“成功”的错误结果。当前90°/180°默认算例没有复现这个问题，但不能将默认通过推广至全部合法输入。

**改进：** 将拟合域与初始化写入配置并做可辨识性检查；对不支持的几何/波长组合明确拒绝或说明边界。初始化可根据观测峰位和独立物性先验设置，并做必要多初值检验；不可用合成真值选解后宣称盲恢复。

### F05 / P2：背景失配没有覆盖探测器背景扣除误差

**证据：** `run_water_simulation.py:223—234` 的相关场景是10%额外弹性光；主流程与噪声函数则按生成时的准确背景扣除。额外弹性光先经过光谱及FP响应，和探测器暗背景、偏置或慢变底线不是同一项。

**影响：** 现有场景可检验一种光学背景，但不能代替新规划M08的完整背景失配。实际测量无法默认背景均值已精确知道。

**改进：** 分开建模光学弹性背景、探测器常数/缓变背景和参考扣除误差，保持生成端与拟合端不同；将背景参考的不确定度计入拟合或误差预算。本轮额外诊断见第5节，未冒充完整M08通过。

### F06 / P2：折叠到一个FSR不意味着非参数谱可唯一恢复

**证据：** `water_simulation/physics.py:188` 和 `run_water_simulation.py:260` 的中文注释出现“唯一恢复”。实际默认算子为350×600；即使行满秩，零空间维数也至少250。四例非参数谱形L2误差为6.46%—63.45%，尽管环曲线残差可以接近噪声。

**影响：** 学习者容易将“不能恢复绝对级次”误读成“单个周期内就能唯一准确恢复”。周期化解决的是表示范围，未解决有限采样、有限分辨率和病态性。

**改进：** 改为“目标是单FSR内的谱表示，恢复仍依赖先验且不保证唯一”；继续分别报告条件频移拟合、非参数谱形误差和正演残差。保留现有方法说明里对欠定反演的正确警告。

### F07 / P2：原包收敛与失配检查尚不是完整验收流程

**证据：** `run_water_simulation.py:157—162` 只比较原步长和半步长；没有四分之一步长或预先确定的误差预算。响应失配主要固定数据而修改拟合端精细度/PSF，属于有用的敏感性检查，但不完全等同于计划表要求的“生成端变化、拟合端固定”的扫描。温度扫描为10/20/30℃的物性输出，没有20/25/30℃贯穿数据生成、拟合和统计的主线验收。

**影响：** 默认数值表现良好，仍不能代替M03或M07的完整计划；温度主目标的证据链尚未完成。

**改进：** 冻结误差预算，覆盖频率网格及必要的成像/反演离散；报告频移、谱宽和图像的收敛指标，按统一方向实施响应/背景/几何失配扫描。优先20/25/30℃频移主线，不扩大盐度、气泡和体黏度研究。

## 3. 可以保留的模型和实现

在明确假设的前提下，本轮没有发现默认频移计算、普通频率/角频率换算、HWHM/FWHM换算或水内角/FP角混用的问题。这里的判断限于检查到的实现和情景，不表示完整水光学谱已通过实验验证。

\[
q=\frac{4\pi n_w}{\lambda_0}\sin\frac{\theta_w}{2},\qquad
\nu_B=\frac{c_s q}{2\pi}=\frac{2n_wc_s}{\lambda_0}\sin\frac{\theta_w}{2}.
\]

`brillouin_ghz` 表示单侧峰相对中心的偏移；两侧峰间距是它的两倍。不能把代码里简写的“spacing”解释成已经是双峰总间距。

\[
D_T=\frac{\kappa}{\rho c_p},\qquad
h_R=\frac{D_Tq^2}{2\pi},\qquad
h_B=\frac{q^2}{4\pi}\left[\frac{4\eta/3+\zeta}{\rho}+(\gamma-1)D_T\right].
\]

上式以普通频率Hz给出半高半宽，FWHM=2h；代码输出再除以10⁹转换为GHz。激光采用高斯FWHM参数，相机PSF采用空间标准差，两者没有混用。

- 水谱来自 `water_simulation` 的水物性和三峰近似，水主流程复用共享的仪器/成像模块，不调用气体谱作为水谱。
- 水内散射角决定q；外部成像角和腔内折射决定FP响应。腔相位折射率与群折射率独立保留，外部空气不自动证明腔内空气。
- 宽频正演计算 \(I(r)=E(r)\int S(\nu)T(\nu,r)\,d\nu\)，然后施加二维轴对称PSF、像素积分和环均值。频率谱没有直接与半径曲线做普通卷积。
- FFT仅为近轴等效频率坐标下的周期卷积对照；本轮与完整正演的相对差为0.187218%。不能将这个近似推广为所有几何下的严格平移不变卷积。
- 谱尾截断面积、非参数谱误差、条件拟合误差分别保留，这是值得保留的记录方式。
- 当前 \((\gamma-1)/\gamma\) 只作为密度涨落近似中央权重；完整光学耦合未实现。体黏度2.5 mPa·s是情景值，不能用于宣称准确的本征线宽温度规律。
- IAPWS物性给出理论参考；低频/热力学声速用于GHz声学峰预测仍带有色散可忽略的模型前提。无噪声回代或共用IAPWS的公式重算不构成独立实验验证。

IAPWS-95官方说明其热力学导数可给出声速、热容等；折射率R9-97推荐波长范围为0.2—1.1 μm，默认0.6328 μm位于其中。本轮核对的是官方发布页和适用范围，不声称重新验证了第三方库的全部实现：[IAPWS-95](https://iapws.org/technical-guidance/release/IAPWS-95)、[R9-97折射率](https://iapws.org/technical-guidance/release/Rindex)。包内使用的是第三方 `iapws 1.5.5`，不是IAPWS机构认证的本项目实验数据。

### 背景与拟合域

将无噪声期望曲线加入每像素背景扣除误差±1、±5电子，再用不含残余背景项的原拟合器拟合。其频移偏差约在-0.0821至+0.0412 MHz之间，平均标准化残差平方约6.93—180.52。这里噪声尺度取默认期望，场景为诊断性假设，不能作为真实背景误差上界；±5电子也不是已知仪器性能。

10°边界反例见F04；60°、90°、180°的同模型无噪声频移检查通过。不能因三个角通过便宣布整个输入域正确。

### 反演可辨识性

默认350×600矩阵，代数零空间维数至少250。本次数值SVD在记录的机器精度阈值下秩为295、奇异值比约7.78×10¹⁶；后两个量随阈值和数值环境改变，不作为精确物理常数。结构性的欠定和强平滑说明必须限制“任意谱唯一恢复”的表述；非负约束和正则化选出的一个解，不自动等于真实谱。

## 7. 建议的修订顺序与再次验收条件

1. 首先修正参数证据状态、运行元数据、优化器/质量双状态及输入域防护。这些直接影响结论可信性，应先于增加更多图和算例。
2. 将新规划写成单独可执行的验收配置：三档各50次、种子、失败判据、误差预算、输出字段和数据类别预先固定。保留旧默认演示，不原位覆盖历史结果。
3. 围绕20/25/30℃频移主线补齐网格和响应/背景/几何失配。优先得到频移偏差、重复离散与可解释的误差预算；线宽及非参数谱恢复作为次级验证。
4. 给每次运行绑定代码哈希、配置哈希、软件版本、时间和输入文件；增加锁定环境及一条不会覆盖历史输出的重跑说明。保留失败与负结果。
5. 实际分析器确定后再接入其响应与原始数据格式。借测或正式实验数据尚未取得，不影响前四项开展；但仿真不能替代结题中可能要求的自测。

本轮到“验收并指出问题”为止，没有自动把修订代码或150次新验证算作已执行。下一步可据此在单独修订副本推进前四项。
