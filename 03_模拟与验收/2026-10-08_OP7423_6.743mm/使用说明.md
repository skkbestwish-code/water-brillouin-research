# 最终交付使用说明

本包默认使用最新修订代码。完整模型、审查发现、正反向误差、数据需求和使用方法统一写在 **研究汇报.md**；本文件仅提供运行入口。

1. 保留解压后的全部目录，先阅读研究汇报。
2. 双击 `运行修订与验收.cmd`。本机已有所需Python环境。
3. 新结果和统一汇报写入 `output/rerun_时间戳/`，不会覆盖已有结果。

在其他环境中先安装依赖，再运行：

```console
python -m pip install -r requirements_verified.txt
python run_all.py
```

主入口执行：37项测试→四算例→150次条件拟合→深入误差检查→统一研究汇报。计算过程中会显示进度，失败时保留日志并停止。IAPWS源码与许可证随`.water_deps/`提供。

首次交付结果位于`output/final_cases/`、`output/final_acceptance/`和`output/deep_review/`。结果是合成模拟，不代表实测精度；默认频移范围先验为0.05–7GHz。

`数据需求清单.csv`供厂家/实验同学补齐；`实验记录模板.json`是实验记录模板，不能作为模拟配置传入。`示例参数_25C.json`和`数值加密配置_仅供继续收敛.json`可给四算例入口使用，完整说明见研究汇报第九节。
