## 运行前期水模拟

在仓库根目录打开终端，进入源码目录（Python 3.10 及以上；历史记录在 Python 3.14.4 下运行）：

```powershell
cd "03_模拟与验收/代码包验收_2026-10-07/原包解压/常压水_瑞利布里渊_FP模拟_2026-10-01"
python -m pip install -r requirements_water.txt
python -m unittest discover -s tests -v
python run_water_simulation.py --output output/local_run
```

请每次使用新的输出目录，保留历史结果。随包 `.water_deps` 包含 iapws 及许可证。方法与输出解释见源码目录中的 `说明_常压水模型方法与结果.md`；科学适用范围与已知缺陷以本次验收报告为准。源码中“已确认参数”和“唯一恢复”等历史表述已被验收报告指出存在问题，本次发布不等于修复这些模型问题。

仪器量级计算可在根目录执行：

```powershell
python "04_仪器选型/仪器选型准备_2026-10-07/选型量级计算.py"
```

补充验收脚本会更新其所在目录的诊断结果，运行前请保存副本；它用于复核既有诊断，不代替新规划的完整模型验证。

## 当前结论与待确认事项

主目标为纯水布里渊频移及其温度依赖。规划中“优先借测”的原假设已有条件更新：导师要求自行搭建光路，设备条件接近零；目前建议评估“自行搭建外部光路＋成熟布里渊频率分析器”。实际预算、分析器是否允许、型号与指导支持仍待确认。10万元为上限假设，不等于经费已批准或到账。

同模型生成再拟合只能检验程序自洽；文献、独立公式和实验验证分别记录。仓库不宣称已完成文献逐篇精读、150次蒙特卡洛验证、采购或实测。
