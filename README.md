## 运行最新代码

下载整个仓库或上方完整交付包，保留目录结构。仓库方式在根目录执行：

```powershell
cd "03_模拟与验收/2026-10-08_OP7423_6.743mm"
python -m pip install -r requirements_verified.txt
python run_all.py
```

Windows也可双击该目录内的“运行修订与验收.cmd”。每次运行生成独立的`output/rerun_时间戳/`目录，包含结果、日志和统一研究汇报，不覆盖已交付结果。`.water_deps`含IAPWS源码与许可证。具体环境、参数设置、数据单位和实测接口限制见[使用说明](03_模拟与验收/2026-10-08_OP7423_6.743mm/使用说明.md)及研究汇报。
